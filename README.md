# 机器学习课程设计竞赛项目
## 项目简介
本项目包含赛道A两套任务代码，全程仅使用传统机器学习算法，无深度学习模型：
1. A1.py：图节点多分类任务
    提取图拓扑特征、标签传播平滑特征，引入KMeans节点聚类扩充特征维度；以XGBoost为主预测模型，额外训练独立决策树作为对比实验，验证梯度树模型优势。
2. A2.py：商品推荐排序任务
    构建用户行为统计特征、物品热度特征，新增用户/物品双维度KMeans聚类特征；使用XGBoost完成点击率预估，依据预测概率生成Top10商品推荐列表。
