# 机器学习课程设计竞赛项目
## 项目简介
本项目包含赛道A两套任务代码：
1. A1.py：图节点多分类任务，使用图拓扑特征+标签传播特征+KMeans聚类，主模型XGBoost，附带决策树对比实验；
2. A2.py：商品推荐排序任务，用户/物品KMeans聚类特征，XGBoost点击率预估生成Top10推荐列表；
全程仅使用传统机器学习算法，无深度学习模型。

## 运行环境依赖
pip install numpy pandas scipy scikit-learn xgboost

## 文件说明
- A1.py：分类任务主代码，输出A1.csv预测文件
- A2.py：推荐任务主代码，输出A2.csv预测文件
- A1.csv / A2.csv：模型预测结果文件

## 复现流程
1. 配置对应文件路径；
2. 先运行A1.py生成分类结果；
3. 再运行A2.py生成推荐结果。
